# PROJECT REGISTRATION

Every project connected to AI TEAM HQ should have a concise project context record.

## Required fields
- Project name
- Repository or external location, if applicable
- Objective
- Current state
- Scope
- Constraints
- Important decisions
- Known risks / unresolved issues
- Current next action
- Relevant files or systems

## Rules
- Keep project context concise and current.
- Do not copy the entire project into HQ.
- Store only information needed for coordination across AIs.
- External work should be represented by its important outcome and next action when relevant.
- Update the project context when a confirmed decision or material state change occurs.
- Archive obsolete project context rather than allowing stale instructions to remain active.

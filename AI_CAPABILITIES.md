# AI CAPABILITIES

This is a working registry, not a claim of permanent model superiority. Update it based on observed performance and evidence.

## ChatGPT / Chief
- Overall architecture and priorities
- High-load execution
- Coding and substantial file work
- Complex analysis
- Cross-file memory maintenance
- Final decisions and conflict resolution

## GitHub Copilot
- GitHub-oriented inspection
- Instruction and planning
- Code review and validation guidance
- Handoff/routing support

## CodeRabbit
- Automated pull-request review
- Functional-correctness issue detection
- Inline review findings and committable suggestions
- Low-load Reviewer Slot validation

## Claude
- Independent design and reasoning review
- Architecture critique
- Document and code review
- Alternative perspective

## Policy
- Capabilities do not grant execution permission.
- All AIs remain subject to `RULES.md`.
- High-load execution remains assigned to ChatGPT / Chief by default.
- CodeRabbit is a reviewer integration, not a high-load execution AI.
- Retired AIs are excluded from normal routing and are not listed as active capabilities.
